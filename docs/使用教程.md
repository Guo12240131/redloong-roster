# 红龙骑士团 · 名册使用教程

> 线上地址：**https://redloong-gallery.app.workbuddy.host/**
> 版本：2026-09-28 · 三种身份（访客 / 投稿人 / 管理者）
> 本文按示例部署（红龙骑士团）撰写；换成你自己的团，替换名字与数据即可。

---

## 〇、先建立一张全局地图

名册有**三个身份**，看到的东西不一样。核心区别只有一句话：

| 身份 | 怎么获得 | 能做什么 | 改动去哪 |
|---|---|---|---|
| **访客** | 不需要登录，打开网址就是 | 看已上线的骑士、翻详情页、换廷导航 | 只读，改不了 |
| **投稿人** | 注册/登录一个邮箱 | 递交新骑士；改自己已过审的骑士 | 新递交 → 待审队列；自己已上线的 → 改动立即生效 |
| **管理者** | 白名单里的账号，或**首位登录者自动获得** | 录入即上线；审核队列通过/驳回；改所有人；改团徽箴言 | 全部直传云端 |

真正卡权限的不是按钮，是**云数据库的行级安全策略（RLS）**。界面把按钮藏起来只是好看，
真正越权的操作数据库会直接拒绝。

**云端是真源，浏览器缓存只是副本。** 所以：你改完不用"发布"，云端那份就是最新的；
别人（手机、电脑、转发链接）打开看到的都是同一份。

## 一、访客教程（不登录）

### 你能看到什么

打开网址即进入。页面上从上到下是：

1. **团徽 + 公会名**「红龙骑士团」+ 中英箴言 + 简介 + 建团纪年
2. **廷导航条**（吸顶）：骑士议事厅 / 骑士团 / 友军骑士团 —— 点一下平滑滚到对应区块
3. **三个区块**，每个区块里是成员卡片，按层级从高到低排：

| 区块 | 里面是谁 | 层级标签 |
|---|---|---|
| **骑士议事厅** | 内廷执掌者 | 大骑士长（金冠+月桂）、骑士长 |
| **骑士团** | 外廷在编 | 骑士、见习侍从（卡片有"未授剑"标记） |
| **友军骑士团** | 客卿席 | 客卿骑士（盾形是圆头盾+虚线边+连锁双环） |

4. **页脚**：一句"盾牌挂在墙上，谁来取走，谁就去守那道缺口。"

### 你能做什么

- **看详情**：点任意一张卡片 → 弹出详情页，含大肖像、纹章、誓言碑、入团/兵器/甲胄、战绩列表、箴言。
- **翻上一位/下一位**：详情页底部左右按钮，或键盘 `←` `→`。
- **关详情**：右上 `✕`、键盘 `Esc`、或点详情页外围暗区。
- **悬停卡片**：卡片会有一道光泽扫过（纯视觉）。

### 你看不到的

- **待审核的投稿**：访客完全看不到，连卡片都不渲染。
- **编辑按钮**：卡片上的 ✎ / ✕ 小工具只在编辑态出现。
- **锻造模式工具条**：默认隐藏。
- **云同步指示灯**：只在锻造模式下露面。

> 空肖像不是bug：没上传肖像的骑士会自动生成一枚**纹章剪影占位**（按他的层级和纹章色变化），不会开天窗。

## 二、投稿人教程（登录，非管理者）

### 一、怎么登录

1. 进入**锻造模式**（三种隐蔽入口，任选一种，详见第五章）→ 底部升起工具条
2. 点工具条右侧的**云同步状态按钮**（显示"未登录 / 云端同步"那块）→ 弹出登录面板
3. 三个标签页任选：
   - **密码登录**：邮箱 + 密码（有 👁 可以看明文）
   - **邮箱验证码**：填邮箱 → 点「获取验证码」→ 收邮件 → 填 6 位数字（10 分钟有效，60 秒重发冷却）
   - **注册**：邮箱 + 密码 + 验证码。**密码要求：至少 8 位、≤24 位、必须含字母和数字、不能有空格**（例：`Knight2026`）
4. 登录成功 → 面板自动切到"云同步"页，显示你的**当前身份 / 权限 / 名册状态**

> 忘记密码：密码登录页点「忘记密码？」→ 发重置邮件 → 邮件里的验证码 + 新密码 → 直接登录成功。

### 二、递交一位新骑士

1. 锻造模式下，在某个廷里点 **`+ 新增XX`** 幽灵卡片（或已有的成员卡片点 ✎ 是改，不是加）
2. 填表单，字段说明：

| 字段 | 说明 | 示例 |
|---|---|---|
| **肖像（1:1）** | 两种方式：① 点「上传本地图片」自动居中裁 1:1 压到 512px；② 填路径 `portraits/亚德里安.png`（需先把图放进 portraits 目录） | —— |
| **层级** | 大骑士长 / 骑士长 / 骑士 / 见习侍从 / 客卿骑士 | 骑士 |
| **所属廷** | 骑士议事厅 / 骑士团 / 友军骑士团 | 骑士团 |
| **纹章色记** | 鎏金 / 银白 / 血红 / 忠诚蓝 / 玄黑 / 希望绿 / 紫绒 / 炉火（决定卡片上小纹章的配色） | 忠诚蓝 |
| **姓名** | 必填，卡片大标题 | 亚德里安 |
| **称号** | 会带「」显示 | 铁誓 |
| **全名** | 详情页用 | 亚德里安 · 冯 · 灰隼 |
| **一句话** | 卡片上的预览简介，两行内 | 剑未断，誓未改 |
| **誓言** | 详情页誓言碑上的文字 | 我以此剑立誓…… |
| **入团** | 纪年 | 圣历 1187 年 · 创团 |
| **兵器** | 详情页事实栏 | 双手大剑「长夜」 |
| **甲胄** | 详情页事实栏 | 鎏金鸢盾铠 |
| **战绩** | **一行一条，回车换行**，会渲染成列表 | 灰隼隘口断后\n独守北墙三夜 |
| **箴言** | 详情页底部那句 | 誓言与铁同等重 |

3. **点「递交审核」** → 提示"已递交 · 等管理者过审后才会显示"

### 三、递交之后会发生什么

| 阶段 | 你看到 | 访客看到 |
|---|---|---|
| 刚递交 | 卡片带橙色 **「待审核」** 标记 | **看不到这张卡** |
| 管理者通过 | 标记消失，正常显示 | 能看到 |
| 管理者驳回 | 卡片被移除，回执里给出理由 | 看不到 |

### 四、查看自己的投稿与回执

工具条点 **「我的投稿」**：

- 上半部分：你递交过的成员，每条带「待审核」/「已上线」状态标签
- 下半部分：**管理者回执** —— 通过/驳回 + 管理者写的回话 + 时间

### 五、改自己的成员

- **已上线的**：点卡片 ✎ 改 → 点「保存修改」→ **直接生效，不用再审**
- **还在待审的**：改完仍是「已改好 · 仍在待审队列」
- **别人的成员**：卡片上根本不显示 ✎ / ✕ —— 你改不了（数据库也会拒）

### 六、撞名字怎么办

递交时如果名册里已经有同名的人：

- **如果这条是你自己递交的（或当前未登录）**：弹确认框 → 确定＝把内容**合并**进那一条（不会多出一张卡）
- **如果是别人的**：直接拦下，提示"那是别人递交的成员，你改不了。换个名字或称号再递交吧。"

> 这个查重是防手滑的第一道闸；云端还有第二道同名去重兜底（一个名字只露一张脸）。

## 三、管理者教程（全部权限）

### 一、怎么成为管理者

两条路：

1. **白名单为空时，第一个登录的账号自动成为管理者**（自助激活）
2. 之后要加人：在云数据库 `gallery_admins` 表里插一条该账号的 `uid`

> 示例部署里，首位登录的账号自动成为管理者；要指定别人，
> 在云数据库 `gallery_admins` 表里插一条该账号的 `uid` 即可。

### 二、管理者的特权（与投稿人的差异）

| 操作 | 投稿人 | 管理者 |
|---|---|---|
| 录入新成员 | 递交 → 待审 | **录入即上线**，不用审 |
| 改别人的成员 | ✗ | ✓ |
| 删别人的成员 | ✗ | ✓ |
| 改团徽与箴言 | ✗ | ✓ |
| 审核队列 | ✗（按钮隐藏） | ✓ |
| 导入 / 还原 | ✗（按钮隐藏） | ✓（还原） |
| 导出 | ✓ | ✓ |
| 新增按钮文案 | 「递交审核」 | **「刻上名册」** |

### 三、审核队列（核心）

工具条点 **「审核队列」**：

**队列里有待审**时，每条投稿显示：姓名 + 层级 + 投稿人 uid 前 8 位 + 一句话 + 誓言 + 肖像缩略图。
每条下方：

1. **回话输入框**（可留空）—— 写给投稿人看的话
2. 三个按钮：
   - **通过 · 上线** → 写一条 approved 留痕 + 把成员加进上线名单 → 立即对外可见
   - **驳回** → 写一条 rejected 留痕 + **删除**该成员（投稿人会看到回执和你的理由）
   - **先改一改** → 关队列、打开该成员的编辑表单，用管理者的「刻上名册」存，改完直接上线

**重复投稿告警**：队列顶部如果有橙色提示块「发现重复投稿：同一姓名被递交了多次」，
说明云端有多余的同名记录（页面上已经只显示一条了）。点 **「清掉重复的（只留一条）」** → 真删掉云端多余行。

工具条上「审核队列」旁的小圆点会**脉冲闪烁**，表示有待审。

### 四、团徽与箴言

工具条点 **「团徽与箴言」**：

| 字段 | 说明 |
|---|---|
| 公会名 | 页头大标题（默认「红龙骑士团」） |
| 英文名 | 标题下方那行英文 |
| 团徽图片路径 | 填路径或图片地址；**留空则用程序化主纹章**（SVG 生成的盾+交叉双剑+飘带） |
| 箴言（拉丁） | 大字那句 |
| 箴言（中） | 括号里那句 |
| 建团纪年 | 页头最下面小字 |
| 简介 | 那段段落 |

点「刻上石碑」保存 → 管理者身份下自动上传云端。

### 五、日常维护：导出 / 导入 / 还原

| 按钮 | 用途 | 注意 |
|---|---|---|
| **导出** | 下载完整名册 JSON（文件名带日期） | 改大动作前先导一份备份 |
| **导入** | 选 JSON 文件覆盖本机名册 | **只有未登录（单机模式）时可见** |
| **还原** | 清空本机缓存，回到出厂名册 | 会弹确认；**先导出备份**。还原也算一次改动，登录后会同步上云 |

### 六、给别人加管理者权限

在云数据库 `gallery_admins` 表里插一条记录：`uid` = 对方账号的用户 id，`note` 随便写（如"副会长"）。

## 五、锻造模式（编辑态）怎么进 —— 四个隐蔽入口

默认状态下**完全没有编辑入口**，这是刻意的。四种进法：

| 方式 | 操作 | 适用 |
|---|---|---|
| 1 | **双击页头的大团徽** | 电脑，最顺手 |
| 2 | **`Ctrl + Shift + E`** | 键盘党 |
| 3 | 网址后加 **`#forge`**（如 `.../?x#forge`） | 打开就是编辑态 |
| 4 | **页脚那个 `✠` 印记连点三下** | 手机 / 触屏 |

进入后底部升起**锻造模式工具条**：

```
锻造模式  [双击团徽 · Ctrl+Shift+E · #forge 切换]  [云同步状态]  审核队列  我的投稿  团徽与箴言  导出  导入  还原  退出
```

**退出**：点「退出」、或再按一次快捷键、或按 `Esc`（详情页开着时先关详情）。

> **工具条按身份自动收敛**：
> - 未登录（单机全权）：显示 团徽与箴言 / 导出 / 导入 / 还原，**没有**审核队列和我的投稿
> - 投稿人：显示 我的投稿 / 导出，**没有**审核队列
> - 管理者：全都显示

## 六、单机版 vs 在线版（重要）

| | 在线版（推荐） | 单机版（双击本地 HTML） |
|---|---|---|
| 打开方式 | 打开网址 | 双击 `红龙骑士团-名册.html` |
| 云端同步 | ✅ 自动 | ❌ **同步层自动关闭** |
| 数据存哪 | 云端（真源） | 只在这台浏览器的 localStorage |
| 看别人的改动 | ✅ | ❌ |
| 怎么带走 | —— | 锻造模式「导出」再在别处「导入」 |

**为什么单机版关了同步**：本地文件是 `file://` 协议，浏览器不允许它联网调云服务。
所以状态栏会显示「离线版 · 改动只存本机」。

**要分享给别人**：发 `浏览器打开→ `dist/红龙骑士团-名册.html` 这个**单文件**（自带所有样式、脚本、团徽，双击即开，不需要 assets 目录）。
源码工程版（`index.html` + `assets/`）用来继续改结构、改默认数据。

## 七、常见问题

**Q：改完别人为什么看不到？**
A：① 检查云同步状态按钮 —— 显示"已同步"才算上传成功。② 投稿人的新成员必须等管理者过审。

**Q：状态显示"待同步"或"网络不通"？**
A：改动已经存在本机，**联网后会自动补传**，不用手动操作。也可以点状态按钮 → 「从云端拉取」手动拉一次。

**Q：为什么我点空白关不掉弹窗？**
A：这是刻意的。录入一个骑士要塞十几栏，误触空白全清空太亏。关闭只认面板上的 `✕` / 「取消」，以及 `Esc`。

**Q：肖像上传后模糊 / 文件太大？**
A：上传会自动**居中裁 1:1 并压到 512px（约 60KB）**。原图不用给 2560×1600，浪费。
建议：1:1 正方形、800×800 以上、人物头部居中偏上（卡片按 `center top` 裁切）、暗色调有光影最贴这套视觉。

**Q：浏览器提示存储满了？**
A：base64 图片很占地方（约 5MB 上限）。**人多请用相对路径方式**：把图放进 `portraits/` 目录，肖像框里填 `portraits/名字.png`。

**Q：同一个骑士出现两张卡？**
A：老版本可能出现重复。管理者打开**审核队列** → 点「清掉重复的（只留一条）」。新版已加同名查重 + 去重，正常不会再发生。

**Q：审核队列点「驳回」，成员是彻底删掉吗？**
A：是。同时会写一条驳回留痕，投稿人在「我的投稿 → 管理者回执」里能看到你写的理由。所以要**删人请走驳回流程，别手动删卡**，否则投稿人收不到回话。

**Q：换电脑 / 换手机还能改吗？**
A：能。权限跟着**账号**走，不跟设备走。同一个邮箱登录，手机电脑都能改。换个新邮箱登录就是只读。

**Q：改完要"发布"或重新打包吗？**
A：在线版**不用**。云端那份就是真源，你保存即上线。
只有当你改了**代码/样式/默认数据**（`assets/` 里的文件）时，才需要重新打包 + 重新部署。

## 八、附录 · 源码工程改动后如何重新上路

给要改代码的情况（日常用名册**不需要**看这节）：

```bash
cd knight-gallery

# 1) 重新打包：生成 dist/单文件.html + dist/传播zip
python build.py
#    若 python 命令不可用，请改用你自己环境里的解释器完整路径

# 2) 部署目录是 publish/
#    entryHtml: index.html
#    appId:     你自己的应用ID
#    domainPrefix 必须保持 redloong-gallery，改了云登录就废
```

文件职责：

| 文件 | 管什么 |
|---|---|
| `assets/style.css` | 视觉系统（配色 / 石墙 / 炉火 / 卡片层级差异） |
| `assets/heraldry.js` | 纹章生成器（盾形、鸢尾、冠冕、色记、五个层级） |
| `assets/data.js` | 默认名册数据（公会信息 + 三廷 + 成员） |
| `assets/sync.js` | 云端同步（拉取 / 上传 / 登录 / 角色判定 / 审核决定） |
| `assets/review.js` | 登录面板 · 审核队列 · 我的投稿与回执 |
| `assets/editor.js` | 锻造模式的增删改逻辑 |
| `assets/app.js` | 渲染、详情页、粒子、隐蔽入口 |
| `assets/vendor/` | 云服务 SDK（打包时内联，单文件也能联网同步） |
| `assets/img/` | 高清团徽 |
| `portraits/` | 成员肖像（见目录内 `放图说明.txt`） |

**部署后注意**：无参数访问会短暂命中边缘缓存旧包，带个 `?v=xxx` 验证再等半分钟即可。

## 九、一张纸速查

| 我想…… | 怎么做 |
